# Материалы для пояснительной записки

## Цель работы

Целью курсовой работы является разработка программного приложения «Система управления онлайн-магазином» с использованием языка Python и принципов объектно-ориентированного программирования.

## Задачи работы

1. Проанализировать предметную область онлайн-торговли.
2. Сформировать функциональные требования к приложению.
3. Спроектировать структуру классов.
4. Реализовать консольное приложение на Python.
5. Проверить корректность работы основных функций.

## Описание предметной области

Онлайн-магазин представляет собой информационную систему, которая обеспечивает взаимодействие покупателя с каталогом товаров. Пользователь может просматривать товары, добавлять выбранные позиции в корзину и оформлять заказ. Администратор отвечает за поддержание каталога в актуальном состоянии.

## Основные классы

- `Product` — описывает товар магазина.
- `User` — абстрактный базовый класс пользователя.
- `Customer` — покупатель.
- `Admin` — администратор.
- `Cart` — корзина покупателя.
- `Order` — заказ.
- `JsonStorage` — хранение данных в JSON.
- `AuthService` — регистрация и авторизация.
- `ProductService` — управление каталогом.
- `OrderService` — оформление и просмотр заказов.

## Тестирование

Тестирование выполнено с помощью модуля `unittest`. Проверялись регистрация и авторизация, добавление и поиск товаров, оформление заказа и изменение остатков товара.
