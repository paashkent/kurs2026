# Система управления онлайн-магазином

Учебный проект для курсовой работы по дисциплине «Объектно-ориентированное программирование с использованием интерпретируемых языков».

## Назначение

Приложение моделирует работу простого онлайн-магазина. В системе есть два типа пользователей: покупатель и администратор. Покупатель может просматривать каталог, искать товары, добавлять их в корзину и оформлять заказы. Администратор может управлять товарами и просматривать заказы.

## Возможности

- регистрация и авторизация пользователей;
- роли `customer` и `admin`;
- просмотр каталога товаров;
- поиск товаров по названию и категории;
- добавление товаров в корзину;
- оформление заказа;
- история заказов пользователя;
- добавление, изменение и удаление товаров администратором;
- хранение данных в JSON-файле;
- обработка типовых ошибок;
- модульная структура проекта;
- тесты на `unittest`.

## Требования

- Python 3.9 или выше;
- PyCharm, VSCode или другая IDE.

## Запуск

```bash
python main.py
```

При первом запуске создается файл `data/store.json` с тестовыми пользователями и товарами.

## Использованные принципы ООП

- **Инкапсуляция**: логика работы с товарами, пользователями, заказами и хранилищем разделена по классам.
- **Наследование**: классы `Customer` и `Admin` наследуются от абстрактного класса `User`.
- **Полиморфизм**: разные типы пользователей реализуют метод `get_permissions()` по-своему.
- **Абстракция**: предметная область описана через сущности `Product`, `User`, `Cart`, `Order`.

## Админская панель

В проект добавлена расширенная админская панель. Для входа можно использовать стандартную учетную запись:

- логин: `admin`
- пароль: `1234`

Возможности администратора:

1. просмотр каталога товаров;
2. добавление новых товаров;
3. редактирование названия, категории, цены, количества и описания товара;
4. удаление товаров;
5. просмотр всех заказов;
6. изменение статуса заказа: `created`, `paid`, `shipped`, `completed`, `cancelled`;
7. просмотр списка пользователей;
8. изменение роли пользователя: `customer` или `admin`;
9. удаление пользователей, кроме главного администратора;
10. просмотр краткого отчета по магазину: количество товаров, пользователей, заказов, сумма выручки и товары с низким остатком.

Админская панель демонстрирует применение разграничения прав доступа, наследования классов `User`, `Customer`, `Admin`, а также работу сервисного слоя приложения.


## Добавленные функции

### Удаление товаров из корзины
Покупатель может открыть меню корзины и удалить товар:
- полностью;
- частично, указав количество для удаления.

### Отмена заказа покупателем
Покупатель может отменить свой заказ через меню «Отменить заказ».
После отмены:
- статус заказа меняется на `cancelled`;
- администратор видит этот статус в списке заказов;
- товары из отмененного заказа возвращаются на склад.


## Доработки версии 1.5

В проект добавлены улучшения безопасности и удобства:

- пароль при входе и регистрации вводится через `getpass`, поэтому не отображается в консоли;
- пароли пользователей хранятся в JSON не открытым текстом, а в виде SHA-256 хеша;
- добавлен поиск заказа по ID для администратора;
- добавлен поиск заказа по ID для покупателя;
- статусы заказов при выводе отображаются на русском языке;
- перед удалением товара или пользователя требуется подтверждение;
- технические папки `__pycache__` не включаются в итоговый архив.

Актуальные статусы заказов:

```text
created   — создан
paid      — оплачен
shipped   — отправлен
completed — завершен
cancelled — отменен
```
